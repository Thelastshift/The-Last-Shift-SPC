THE LAST SHIFT — LEADERBOARD SETUP

1. Open your Supabase project.
2. Open SQL Editor and run the following SQL:

create table if not exists public.game_scores (
  id bigint generated by default as identity primary key,
  game_name text not null,
  player_name text not null,
  linkedin_id text not null,
  score integer not null check (score >= 0 and score <= 100),
  ending text not null,
  created_at timestamptz not null default now()
);

alter table public.game_scores enable row level security;

create policy "Public can submit game scores"
on public.game_scores for insert
to anon
with check (true);

create policy "Public can view game leaderboard"
on public.game_scores for select
to anon
using (true);

3. In Supabase, open Project Settings > API.
4. Copy the Project URL and the public anon key.
5. Open config.js and replace both placeholder values.
6. Upload index.html, config.js and the images folder to GitHub.

Privacy: LinkedIn IDs are saved in Supabase for organiser verification, but index.html does not display them on the public leaderboard.

Player entry rule: The registration form accepts only a LinkedIn ID, such as rohith-satheesh. Full LinkedIn URLs are rejected.
